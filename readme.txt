A lightweight, classic WordPress theme for editorial news sites.

== Setup ==
1. Activate Meridian News under Appearance > Themes.
2. Assign a Primary Menu under Appearance > Menus.
3. Set a Posts page under Settings > Reading to use the blog layout.
4. Add a logo under Appearance > Customize > Site Identity (optional).

== Features ==
Native post archives, author archives, search, comments, responsive navigation, related posts, and accessible editorial layouts.
